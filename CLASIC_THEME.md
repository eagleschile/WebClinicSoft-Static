# Tema "Clásic" — Paleta de colores (respaldo)

Este tema fue el predeterminado original de la aplicación (carpeta `templates/default`,
`themeName: "Dflow"`). Se eliminó de la app para dejar únicamente **DocuMed Glass** como
tema base. Se conserva aquí su paleta por si se requiere restaurarlo o referenciarlo.

## Colores

| Tokens | Hex | Uso |
|--------|-----|-----|
| `primary` | `#2563eb` | Color primario (azul) |
| `primaryDark` | `#1d4ed8` | Variante oscura del primario |
| `bg` | `#f1f5f9` | Fondo general (claro) |
| `surface` | `#ffffff` | Superficie de tarjetas/paneles |
| `text` | `#0f172a` | Texto principal |
| `muted` | `#64748b` | Texto secundario/muted |
| `border` | `#e2e8f0` | Bordes |
| `success` | `#16a34a` | Éxito |
| `danger` | `#dc2626` | Peligro/error |
| `warning` | `#d97706` | Advertencia |
| `sidebarBg` | `#0b1220` | Fondo de la barra lateral (oscuro) |
| `sidebarText` | `#cbd5e1` | Texto de la barra lateral |

## Otros tokens

- `radius`: `18px` (esquinas redondeadas)
- `font`: `'Segoe UI', system-ui, -apple-system, sans-serif`

## Notas

- Tema claro con sidebar oscuro (contraste mixto).
- Reemplazado por **DocuMed Glass** (carpeta `templates/documed-pro`), tema oscuro
  con superficies de vidrio (glassmorphism) y acentos `#7aa3ff` / `#9b7cff`.
